# Install this GitHub profile

1. Open the special profile repository: `CODEMASTER-284/CODEMASTER-284`.
2. Upload `README.md`, the `assets` folder, and the `.github/workflows/snake.yml` file while preserving the same folder structure.
3. Commit the files to the default branch.
4. Open **Actions → Generate contribution animation → Run workflow** once.
5. In **Settings → Actions → General → Workflow permissions**, enable **Read and write permissions** if the workflow cannot publish the `output` branch.

The custom SVG files are self-owned and do not depend on an external banner generator. GitHub’s own image proxy may cache updates briefly after a commit.
