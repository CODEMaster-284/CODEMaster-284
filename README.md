## 03 / Flagship product — EDUVATE CBT

**Founder & CTO · Full-stack product architect · Lead engineer**

[![Website](https://img.shields.io/badge/Explore_EDUVATE-E3B83F?style=for-the-badge&logo=googlechrome&logoColor=090D15)](https://eduvate.com.ng)
[![Google Play](https://img.shields.io/badge/Android_App-111827?style=for-the-badge&logo=googleplay&logoColor=E3B83F)](https://play.google.com/store/apps/details?id=com.eduvate.practicehub)
[![Product demo](https://img.shields.io/badge/Platform_Demo-111827?style=for-the-badge&logo=youtube&logoColor=E3B83F)](https://youtu.be/raULhwC4TtE)
[![Mobile demo](https://img.shields.io/badge/Mobile_Demo-111827?style=for-the-badge&logo=youtube&logoColor=E3B83F)](https://youtu.be/Qlz04x5xMz0)

**EDUVATE CBT** is an AI-enhanced educational ecosystem for institutions, teachers and students. I developed its core product architecture, exam engine, web workflows, dashboards, API integrations and companion React Native application.

| Product area | Engineering delivery |
| :--- | :--- |
| **CBT / assessment** | Timed and randomized exams, question banks, multiple answer formats, access controls, grading and controlled result publication |
| **LMS** | Courses, assignments, live learning, attendance and gradebook workflows |
| **Practice Hub** | Exam-preparation practice, AI explanations, personalized learning and student analytics |
| **Exam integrity** | Google Cloud Vision-assisted proctoring, configurable monitoring and review evidence |
| **Mobile** | React Native + Expo student learning application, API connectivity and notifications |
| **Institutional tooling** | Admin/teacher dashboards, subscription flows, reporting, bulk onboarding and email workflows |

**Architecture in practice**

```text
Students / Teachers / Institution Administrators
                        │
           Web Platform + Mobile App
                        │
            Authentication & RBAC
                        │
         Exams / LMS / Practice / Analytics
                        │
            PHP Services + MySQL
                        │
    Gemini · Cloud Vision · Payments · SMTP · FCM
                        │
          Ubuntu VPS + Nginx + PHP-FPM
```

This is a real production product serving educational workflows, not a tutorial or demonstration project.
